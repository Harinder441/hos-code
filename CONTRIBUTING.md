# Contributing to hos-code

hos-code is a fork of [px0](https://github.com/px0-ai/px0) maintained as the Code view of
[hos](https://github.com/Harinder441/hos).

- Bugs and ideas: open an issue in [hos Issues](https://github.com/Harinder441/hos/issues/new?template=hos-code.yml)
  (it is labelled `hos-code`). Include your OS, browser, `hos-code -version`, and steps to reproduce.
- Pull requests: welcome when small and focused. Run `make check` first; keep the binary single and static, with no
  runtime downloads.
- Bugs that also exist in upstream px0 are worth reporting there too.
